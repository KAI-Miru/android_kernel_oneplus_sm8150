Literal stock-config failure and fix
====================================
Unmodified olddefconfig silently drops the legacy OPPO_* symbols. Meanwhile
OplusKernelEnvConfig.mk unconditionally defines OPLUS_FEATURE_HEALTHINFO.
include/linux/blkdev.h then suppresses the normal request_queue::in_flight
field, but only re-adds its OPlus form under CONFIG_OPLUS_HEALTHINFO. Compilation
therefore fails at queue_in_flight() with “no member named 'in_flight'”.

drivers/soc/oplus/Kconfig now accepts all 27 legacy symbols and makes the ten
enabled legacy settings select their renamed OPLUS equivalents. No C code was
changed. This intentionally changes which existing code is compiled relative
to the broken literal olddefconfig result; it restores the production config's
intended feature selection.

Final config versus stock
=========================
All stock symbols and values are retained. scripts/diffconfig reports only 17
new symbols: 13 modern OPLUS equivalents/defaults and four new touch defaults.
The final .config is therefore not byte-identical to stock, but the old feature
names no longer disappear and the renamed implementations are enabled.
