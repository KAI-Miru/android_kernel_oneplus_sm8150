# 米乳内核 Miru H.40 Linux 4.14.305 更新日志

- 内核版本由 Linux 4.14.269 更新至 Linux 4.14.305，并完整保留 Android Common 4.14.305 的真实提交与双亲合并历史。
- 修复 4.14.287 及 4.14.291 完整候选版本中出现的首屏卡死问题；为随机数初始化线程保留适配 OnePlus H.40 启动顺序的 `system_wq` 早期启动保护。
- 修复 Qualcomm extcon 阻塞通知链的分配、初始化与释放生命周期，降低 USB、充电和外接状态切换路径中的内存与通知链风险。
- 合并 ARM64 CPU 勘误与安全缓解更新，同时保留 OnePlus/Qualcomm Kryo 处理器识别、SMCCC 回调和 H.40 平台行为。
- 更新早期 FDT 映射路径，使用公开接口并保留下游 `of_fdt_get_ddrtype()`，确保 H.40 内存类型读取和 SM8150 启动兼容性。
- 更新 Qualcomm early-random 代码所需的随机数与硬件随机数接口，避免与 Linux 4.14.305 随机数子系统不匹配。
- 完成 33 项真实语义冲突逐项处理：33 项已解决，剩余 0 项；未使用整体 `ours`/`theirs` 覆盖，也未扁平化 Android Common 历史。
- 三方审计通过：Android Common 4.14.269→4.14.305 范围内 2,777 个提交全部存在，36 个稳定版端点合并全部保留，未发现意外丢失的 H.40/Oplus 路径或配置项。
- 保留 Miru H.40 原有 KCAL 屏幕 RGB 校准功能，以及已验证的刷新率、AOD、指纹 HBM、音频、NFC、充电和 USB 相关下游适配。
- 构建验证包含 5 个生产 DTB、13 个内置模块和 32 个外部模块；最终 ELF/MODVERSIONS CRC 审计错误为 0。
- Linux 4.14.305 必须搭配同一构建产物中的 4.14.305 外部模块使用，禁止混用 4.14.269、4.14.241、旧版 Miru 或原厂模块。
