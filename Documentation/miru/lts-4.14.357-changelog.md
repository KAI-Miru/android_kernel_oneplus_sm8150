# 米乳内核 Miru H.40 Linux 4.14.357 更新日志

内核基础由 Linux 4.14.336 升级至 OpenELA Linux 4.14.357，整合近 2,000 项上游长期维护修复。

- **存储更可靠：**修复 Qualcomm UFS 初始化、控制器中断与 UIC 命令时序，以及 F2FS 目录项、Ext4 块管理和异常路径问题；降低安装应用、解压、复制文件和系统清理时偶发卡顿、文件系统报错或异常重启的风险。
- **系统更稳定：**修复 Android Binder 异步事务、进程退出和读取线程的竞争/卡死问题，减少高后台负载下偶发的应用无响应、系统服务卡住或重启。
- **连接更稳：**合入 TCP 重传计时、IPv4/IPv6 网络处理、无线网络和蓝牙连接生命周期的修复，改善长时间联网、网络切换与蓝牙连接时的稳定性。
- **降低偶发崩溃风险：**修复多处内存越界、重复释放、竞态和溢出问题，减少少数场景下死机、重启或数据异常的概率。

## 米乳专项修复

移除了 Oplus 下游遗留的 `trace_printk()` 调试错误。此前该代码会在开机时触发 trace 调试缓冲初始化，使 dmesg 显示 “DEBUG kernel” 警告；现已完全消失，并避免预留约 **11 MiB** 的追踪缓冲内存。

本版本必须搭配同一 `4.14.357-openela-miru-ci1+` 构建产物中的外部模块；不要与 4.14.336、旧版 Miru 或原厂模块混用。
