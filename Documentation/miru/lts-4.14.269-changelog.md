# 米乳内核 4.14.269 更新日志

适用于 OnePlus 7 Pro（guacamole）。本次从 Linux 4.14.241 更新到 Linux 4.14.269，并加入 KCAL 屏幕色彩校准功能。

## 重点功能：KCAL 屏幕 RGB 校准

- 新增 KCAL 色彩校准：可独立调整红、绿、蓝三色强度，让屏幕色温和观感更贴合个人偏好。
- 提供 `kcal`、`kcal_enable` 和 `kcal_min` 控制项；支持开关校准与限制最低色彩值。
- 调整后会立即请求显示刷新，无需重启才能看到色彩变化。
- KCAL 在显示 PCC 色彩通路中工作，不替换系统原有的色彩配置；关闭或使用中性值时会保留原有显示效果。
- 已完成编译、32 个外置模块和 ABI 检查，并已在真机确认可用。

## 系统稳定性与日常流畅度

- Linux 内核由 4.14.241 升级至 4.14.269，包含 Android Common stable 的安全性与正确性修复。
- 修复内存压缩、共享图形缓冲区、内存回收和异常内存压力路径中的问题，降低高负载、多应用切换或图形任务下偶发卡顿、冻结和异常退出的风险。
- 修复部分调度器和 CPU 热插拔相关的生命周期问题，改善极端场景下的系统响应可靠性。

## 存储、应用安装与文件读取

- 改善 UFS、FUSE 与 Incremental FS 相关的错误处理和资源释放。
- 提升大型应用安装、更新、按需读取及异常 I/O 场景下的稳定性，降低偶发读取失败或卡住的风险。

## USB、调试与连接电脑

- 修复 DWC3、USB Gadget、FunctionFS、RNDIS 与复合 USB 设备的多项边缘问题。
- 改善连接电脑、ADB 调试、文件传输、USB 网络共享和 USB 模式切换时的可靠性。

## 显示、网络与无线连接

- 改善 DSI 显示驱动的错误处理和资源管理，增强显示初始化、刷新和异常恢复路径的可靠性。
- 改善蓝牙核心连接与音频链路中的锁定和资源处理，降低少数异常连接场景的问题概率。
- 更新网络协议与数据包处理的安全性和正确性修复，改善复杂网络环境下的稳定性。

## 已验证

- 真机内核版本：`4.14.269-miru-h40-lts269-14d41d8-ci3+`。
- OnePlus 7 Pro 已完成刷入、启动与日常功能验证；维护者于 2026-07-27 再次确认工作正常。
- 完整构建已通过：内核、32 个外置模块和 ABI 检查均成功，ABI 错误为 0。

本更新不宣传未经验证的性能或续航提升；重点是让系统、显示、存储、USB 和连接功能在新稳定版内核上保持可靠。
